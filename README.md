### 📌 Projetos em Destaque

**🛡️ [DPO Fast (Guardiao-compliance)](https://github.com/Felip3Sadrak/Guardiao-compliance)**
Micro-SaaS para adequação à LGPD. Plataforma completa com questionários iterativos por setor, geração de relatórios em PDF com IA (Qwen AI), gestão de to-do lists, upload de documentos e assinaturas via Stripe. Arquitetura focada em segurança e escalabilidade.
`Stack: React, Node.js, Firebase, Qwen AI, Stripe` | [Ver Repositório](https://github.com/Felip3Sadrak/Guardiao-compliance)

**🏙️ [Guia da Cidade](https://github.com/Felip3Sadrak/guia-da-cidade)**
Solução white-label para municípios conectarem cidadãos a notícias, eventos e diretório comercial. Sistema de permissões (RBAC), painel administrativo com auditoria completa e dashboards de performance em tempo real.
`Stack: React 19, TypeScript, Tailwind CSS, Firebase (Firestore & Auth), Vite` | [Ver Repositório](https://github.com/Felip3Sadrak/guia-da-cidade)

**🎓 [Futurize](https://github.com/Felip3Sadrak/Futurize)**
Gerenciador de projetos acadêmicos com quadro Kanban, colaboração em equipe e acompanhamento de prazos. Solução multiplataforma (web e mobile) desenvolvida como projeto integrador na FATEC.
`Stack: Java, Spring Boot, SQL, React JS, React Native` | [Ver Repositório](https://github.com/Felip3Sadrak/Futurize)

**✂️ [Docks Barber](https://github.com/Felip3Sadrak/docks-barber)**
Sistema de gestão e agendamento para barbearias, com controle de serviços, profissionais e histórico de clientes. Interface moderna e fluxo de agendamento otimizado.
`Stack: Node.js, React 19, TypeScript, Tailwind CSS, Firebase (Firestore & Auth), Vite` | [Ver Repositório](https://github.com/Felip3Sadrak/docks-barber)

**📧 [PST Manager](https://github.com/Felip3Sadrak/pst-manager)**
Ferramenta desktop avançada para gerenciamento, backup, divisão e criptografia de arquivos PST (Outlook). Desenvolvida em Python com integração nativa ao Windows via COM API, suporte a parsing puro (sem Outlook) e criptografia em repouso. Distribuição facilitada via executável (`pst-manager.exe`) gerado em pipeline de CI.
`Stack: Python, pywin32 (Outlook COM), pypstreader, Cryptography, CI/CD` | [Ver Repositório](https://github.com/Felip3Sadrak/pst-manager)
